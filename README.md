# 麦理浩径第二段 · 两天一夜徒步日程表

> 深圳出发 · 破边洲 · 万宜水库 · 西湾露营 · 贵阳往返
> 一份把车程、徒步、班次全部换算成钟点的可执行行程表。

单文件 HTML,双击即可打开,无外部依赖。全部照片已内嵌为 base64,**断网也能看**。

## 行程概览

| | 日期 | 安排 |
|---|---|---|
| 前一晚 | 10/27（二） | 贵阳 → 深圳,住福田口岸附近,买齐干粮 |
| **D1** | 10/28（三） | 06:30 深圳出发 → 07:35 过关 → 09:00 东坝起步 → 徒步 → 16:15 西湾扎营 |
| **D2** | 10/29（四） | 07:00 看日出 → 10:00 撤营 → 12:45 到深圳北站 → 14:32 G2930 回贵阳 |

**核心数字**：徒步 8.5-9 km · 累计爬升约 300 m · 净徒步 5-6 小时 · 人均市内交通约 190 港币

## 票务建议

| | 车次 | 时刻 | 二等座 |
|---|---|---|---|
| 去程（10/27） | **G2921** | 贵阳北 11:14 → 深圳北 15:47 | **¥496.5** |
| 返程（10/29） | **G2930** | 深圳北 14:32 → 贵阳东 19:40 | **¥444.5** |

选高铁而非飞机的理由：加上提前 2 小时到机场、两地机场往返与摆渡，飞机总耗时与 4h30 的高铁相当，票价还贵 200-500 元。真正的优势是"前一晚能到深圳、把干粮买齐"。

## 三个关键提醒

1. **10/28 是工作日，破边洲不需要预约。** 渔护署的预约制只覆盖 9/5-6、9/12-13、9/19-20、9/25-27 与 10/1-7，10/28 不在其中。
2. **9A 专线小巴工作日不开**，去程必须拼的士到东坝（四人分摊约 88 港币/人）。
3. **西湾营地在「大浪西湾北面沙滩」**，南面近士多的那片不是营地。渔护署提示须小心潮水上涨。

## 目录结构

```
.
├── 麦理浩径第二段_深圳往返徒步日程表.html   # 主交付物,单文件,自包含
├── light.css                                  # 样式源文件
├── build.py                                   # 构建脚本(读取 light.css 并内联图片)
└── img/                                       # 图片源文件
    ├── src/     # 原始下载
    ├── opt/     # 首次压缩
    └── final/   # 构建用最终版
```

### 修改与重新构建

```bash
python build.py
```

`build.py` 会读取 `light.css`、把 `img/final/` 下的图片压缩为 base64 并内联进 HTML。改样式只需编辑 `light.css` 后重跑,不必手工改 HTML。
